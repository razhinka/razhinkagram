# razhinkagram

Легковесный многопоточный TCP-чат, написанный на стандартной библиотеке Java 21.
Серверная часть использует виртуальные потоки (Virtual Threads) для обработки множества одновременных подключений. Клиентская часть реализована с графическим интерфейсом на базе Java Swing.

Ключевые особенности:
* Широковещательная рассылка сообщений (Broadcast).
* Безопасное разделяемое состояние (потокобезопасные коллекции).
* Корректное завершение сессий (Graceful disconnect).

## Инструкция по запуску

Для запуска у вас должны быть установлены **Java 21** и **Maven**.
Сначала скомпилируйте и упакуйте проект в исполняемые `.jar` файлы:

```bash
mvn clean package
```

### Запуск сервера
Сервер запускается в консольном режиме. Выполните команду в корневой папке проекта:

```bash
java -jar target/razhinkagram-1.0-SNAPSHOT-server.jar
```

### Запуск клиента
Откройте новую вкладку терминала и запустите графический клиент:

```bash
java -jar target/razhinkagram-1.0-SNAPSHOT-client.jar
```

*Вы можете открыть несколько вкладок и запустить несколько клиентов одновременно, чтобы протестировать обмен сообщениями.*
